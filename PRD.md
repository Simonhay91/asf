# PRD — РусскийАсфальт (russkiyasphalt.ru)

## 1. Проблема

Компания по асфальтированию не имеет органического трафика из поиска.
Конкуренты в нише (Москва + Подмосковье) занимают первые позиции через большое
количество локальных страниц и SEO-контент. Ручное создание контента масштабируется
плохо — нужна автоматизация.

---

## 2. Цель продукта

Создать SEO-машину: сайт, который каждый день автоматически публикует уникальный
контент (страницы районов, городов, блог) и индексируется поисковиками, генерируя
органический трафик и заявки на асфальтирование.

**Целевые метрики (6 месяцев):**
- 500+ страниц в индексе Яндекса
- 1 000+ органических визитов/месяц
- 20+ заявок/месяц через форму

---

## 3. Пользователи

| Сегмент | Описание |
|---|---|
| **Владелец** | Управляет контентом через Telegram-бота |
| **Клиент (B2C)** | Ищет асфальтирование у своего дома/дачи в Подмосковье |
| **Клиент (B2B)** | Ищет подрядчика для промышленной территории, парковки |

---

## 4. Архитектура системы

```
Telegram Bot
    ↓ /generate [blog|moscow|podmoskovye|both]
Generate Service
    ├── Perplexity Sonar  → research (факты, нормы, локальный контекст)
    ├── Claude Sonnet     → написание контента (1500–2200 слов)
    └── Pexels API        → обложка статьи/страницы
         ↓
    MongoDB (generated_pages)
         ↓
    Sitemap rebuild → Yandex ping
         ↓
    FastAPI → React Frontend
```

## 5. Контент-машина

### 5.1 Типы страниц

| Тип | Количество | URL-шаблон | Статус |
|---|---|---|---|
| Район Москвы | 125 | `/moskva/{okrug}/{slug}/` | 🔄 В очереди |
| Город Подмосковья | 80 | `/podmoskovye/{slug}/` | 🔄 В очереди |
| Блог-статья | 100 | `/blog/{slug}/` | 🔄 В очереди |
| Сервисные страницы | 5 | `/uslugi/{slug}/` | ✅ Готово (статика) |

### 5.2 Стили контента (7 вариантов)

Каждая страница генерируется в одном из 7 стилей, чтобы контент не повторялся:
1. Проблема → Решение → Цены → Этапы → CTA
2. Преимущества → Услуги → Работы → Цены → CTA
3. Цены сразу → Почему мы → Процесс → Гарантии → CTA
4. Локальный контекст → Что делали → Услуги → Цены → CTA
5. FAQ → Услуги → Цены → Отзывы → CTA
6. Сравнение материалов → Рекомендация → Работы → Цены → CTA
7. Этапы пошагово → Важность → Цены → CTA

### 5.3 Блог-темы (100 штук)

Разбиты на 5 категорий, каждая со своим стилем написания:

| Категория | Кол-во | Стиль |
|---|---|---|
| `technical` | 20 | Экспертная: проблема → техническое объяснение → советы |
| `business` | 20 | Деловая: ситуация → анализ → список советов |
| `local` | 20 | Локальная: контекст Москвы/МО → специфика → опыт |
| `problems` | 20 | Решение: проблема → причины → устранение → профилактика |
| `inspiration` | 20 | Вдохновение: образ → возможности → примеры → CTA |

### 5.4 Pipeline одной блог-статьи

```
1. Взять следующий pending топик из blog_topics (по priority_order)
2. Perplexity: собрать актуальные факты и нормативы по теме
3. Claude: написать 1400–1800 слов с internal links + meta
4. Pexels: получить обложку по slug/keywords
5. Сохранить в generated_pages (upsert)
6. Обновить статус топика: pending → done
7. Rebuild sitemap → Yandex IndexNow ping
8. Telegram уведомление
```

## 6. Frontend

### 6.1 Страницы

| Роут | Компонент | Описание |
|---|---|---|
| `/` | `Home.jsx` | Главная: hero slider, услуги, цены, калькулятор, проекты, отзывы, FAQ, карта городов |
| `/blog/` | `BlogList.jsx` | Список всех статей с обложками |
| `/blog/:slug` | `Blog.jsx` | Статья + sidebar (похожие статьи, города) |
| `/moskva/:okrug/:slug/` | `District.jsx` | Страница района + полезные статьи |
| `/podmoskovye/:slug/` | `City.jsx` | Страница города + полезные статьи |
| `/uslugi/:slug/` | статика | Сервисные страницы |

### 6.2 Ключевые UX-элементы

- **QuoteModal** — форма «Получить расчёт», отправляет данные в Telegram
- **Калькулятор** — онлайн расчёт стоимости по площади и типу работ
- **Hero Slider** — 3 слайда с реальными фото (Pexels)
- **Карта присутствия** — 80+ городов Подмосковья, clickable chips

## 7. Internal Linking Strategy

```
Home ──→ /uslugi/* (услуги)
Home ──→ /blog/ (последние 3 статьи)
Home ──→ /podmoskovye/* (карта городов)

Blog ──→ /uslugi/* (2–3 ссылки в тексте)
Blog ──→ другие /blog/* (похожие статьи в sidebar)
Blog ──→ /podmoskovye/* (города в sidebar)

District/City ──→ /blog/* (секция «Полезные статьи»)
District/City ──→ /uslugi/* (в тексте)
```
