# План максимальной видимости — Москва и округа

## Цель
Лидерство в long-tail по запросам «асфальтирование + район/округ + цена» в Москве.

## Архитектура URL (3 уровня)

```
/moskva/                          — 125 районов, 10 округов
/moskva/{okrug}/                  — хаб округа (ЦАО, ЮВАО…)  ← NEW
/moskva/{okrug}/{district}/       — район (AI-контент, cron)
```

## Ритм контента (cron)
- **4 района/день** (09:00 + 18:00 МСК) → ~25 дней до 125/125
- После Москвы: 2 города МО + блог по прайс-запросам

## P0 — техническое (сделано / deploy)
- [x] Уникальные title через `/__spa` + nginx `@spa`
- [x] 10 страниц округов `/moskva/uvao/` …
- [x] Прайс под запросы «площадка», «двор», «цена за м²»
- [ ] Яндекс.Бизнес + отзывы на Картах
- [ ] ИНН/СРО на «О компании»

## P1 — контент (2–4 недели)
- Блог: «Сколько стоит асфальтирование площадки в Москве»
- Услуга дворов: H1 «частный дом», FAQ schema
- Внутренние ссылки: прайс → округ → район → услуга

## P2 — доверие и CTR
- Реальные фото объектов в Москве (портфолио)
- Переобход топ-URL в Вебмастере после каждого deploy
